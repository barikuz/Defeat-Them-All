# 🗡️ Defeat Them All

A fast-paced, straightforward 2D pixel-art platformer built with **Unity 6**. Jump across platforms, clear rooms filled with enemies, and unlock your way to victory!

🎮 **[Play the Game on itch.io](https://mutedsoul.itch.io/defeat-them-all)**

📱 **[Download for Android (APK)](https://github.com/barikuz/Defeat-Them-All/releases/download/v1.0.0/DefeatThemAll.apk)**

---

## 📖 About the Game

Pure old-school combat and platforming action. Progress through 3 escalating stages, defeat all enemies in each room to unlock the exit door, and beat the game.

### 🎯 Level Progression

* **Room 1:** Defeat **3 enemies** across the platforms to unlock the bottom-right exit door.
* **Room 2:** Clear out **5 enemies** to advance further.
* **Room 3:** Face the final challenge with **7 enemies** positioned on trickier platforms. Clear them all to open the final door and win!
* **Checkpoint System:** If you get defeated, you restart right from the current level.

## 🚀 Getting Started (For Developers)

If you want to inspect or run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/barikuz/Defeat-Them-All.git
   ```
2. Open **Unity Hub** and click **Add > Add project from disk**.
3. Select the cloned project folder (Recommended: **Unity 6**).
4. Open the `MainMenu` scene under `Assets/Scenes/` and press **Play**.
